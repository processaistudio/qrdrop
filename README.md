# QR Drop

Web de [QR Drop](https://processaistudio.github.io/qrdrop/): passa fitxers del PC a qualsevol dispositiu amb un QR, sense cap connexió.

- `index.html`: la pàgina (estàtica, sense dependències).
- Instal·lador: a [Releases](https://github.com/processaistudio/qrdrop/releases).

El codi de l'aplicació és en un repositori a part.
